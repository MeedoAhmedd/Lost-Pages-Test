# Asset Licenses

Every third-party asset shipped in a commercial release — music, sound effects,
fonts, textures, models, icons — must have its license recorded here **before**
that release. "Royalty free" alone is not proof of unrestricted commercial use;
record the actual terms.

For each asset, note:

- **Asset name / filename**
- **Creator**
- **Source** (where it was obtained)
- **License** (e.g. CC0, a specific marketplace license)
- **Commercial-use permission** (yes/no, and any conditions)
- **Attribution requirement** (yes/no, and the required credit text)
- **Date added**
- **Receipt / source page** (link or reference, where applicable)
